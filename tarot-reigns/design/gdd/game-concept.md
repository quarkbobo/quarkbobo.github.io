# Tarot Reigns — 游戏设计文档 (GDD)

## 一、游戏概述

| 项目 | 内容 |
|------|------|
| **游戏名称** | Tarot Reigns / 塔罗统治 |
| **类型** | 卡牌决策 / 叙事生存 / Roguelite |
| **核心玩法** | 左右滑动卡牌做出"是/否"决策，平衡四维元素 |
| **目标平台** | Windows / macOS / Linux |
| **引擎** | Python + Pygame |
| **参考** | Reigns (Nerial/Devolver)、Tinder 交互 |

---

## 二、核心机制

### 2.1 滑动决策

- **左滑** = 拒绝（否）
- **右滑** = 同意（是）
- 滑动到一定角度时，四元素头顶显示 ±圆圈，实时反馈决策影响

### 2.2 四维平衡系统

| 元素 | 对应 | 初始值 | 范围 |
|------|------|--------|------|
| 🔥 火（权杖） | 野心/动力 | 50 | 0–100 |
| 💧 水（圣杯） | 情感/社交 | 50 | 0–100 |
| 🌪️ 风（宝剑） | 思维/学业 | 50 | 0–100 |
| 🪨 土（星币） | 资金/物质 | 50 | 0–100 |

**规则**：任一数值归零或满格 → 触发对应结局，游戏结束。

### 2.3 时间机制

- **单位**：天 → 周（7天）→ 年（52周）
- 每张卡牌消耗 1 天
- 结算时显示存活天数/周数/年级

### 2.4 塔罗牌系统

- **开局**：随机获得一张塔罗牌（大阿尔卡纳）
- **容量**：最多携带 1 张
- **使用**：任意时刻可使用，立即生效
- **获取**：特殊事件中可能获得新的塔罗牌

| 塔罗牌 | 效果 |
|--------|------|
| 愚者 | 火水风土全部重置为 50，时间 -7天 |
| 魔术师 | 火水风土各 +20 |
| 女祭司 | 随机两项元素 ±15 |
| 皇帝 | 火 +30，水 -10 |
| 恋人 | 水 +25，风 -5 |
| 战车 | 火 +20，风 +15 |
| 力量 | 全部 +10 |
| 隐者 | 风 +30，火 -10 |
| 命运之轮 | 四元素随机 ±10~20 |
| 正义 | 四元素中最高的 -20，最低的 +20 |
| 倒吊人 | 时间 +7天，全部 -5 |
| 死神 | 全部 -15，获得一张新塔罗牌 |
| 节制 | 全部向 50 靠近 15 |
| 恶魔 | 全部 +25，但下一次决策后果翻倍 |
| 塔 | 随机一项归零，其他 +15 |
| 星星 | 全部 +15 |
| 月亮 | 下三张卡牌效果随机化（隐藏显示） |
| 太阳 | 全部 +20，时间 -3天 |
| 审判 | 全部变为 60 |
| 世界 | 全部 +25 |

### 2.5 恶魔节点

- **Year 1**：校园舞会（第 30 周附近）
- **Year 2**：校园舞会（第 82 周附近）
- **Year 3**：校园舞会（第 134 周附近）
- 恶魔出现时强制进入特殊剧情线

## 三、八种结局

### 结局一：🔥 燃烧殆尽 —「野心焚身」

> 火元素达到 100

你太想进步了。学生会、竞赛、实习、创业……你把生活的一切都抛在脑后。
凌晨三点的图书馆，你的眼睛布满血丝，你感到一阵眩晕——
然后你倒下了。没有人知道你最后在做什么。
**恶魔低语**：「如此拼命，也不过是一捧灰烬罢了。」

### 结局二：💧 溺于深情 —「泪海沉沦」

> 水元素达到 100

你沉迷于每一段关系，为每一个微笑心动，为每一次冷漠心碎。
你的眼泪汇成了河，你的执念筑成了牢。在一次疯狂的告白被拒后，
你哭着哭着就再也停不下来了——直到泪水将你淹没。
**恶魔低语**：「爱得太多，和从未爱过，其实一样。」

### 结局三：🌪️ 思维风暴 —「精神囚笼」

> 风元素达到 100

你的大脑从未停止运转。哲学、数学、物理——你试图用理性解释一切。
但你越想越疯，现实与妄想开始混淆。你被送进了精神病院，
每天对着墙壁推导"宇宙真理"，没有人听得懂你在说什么。
**恶魔低语**：「想太多的人，最终会困在自己编织的网里。」

### 结局四：🪨 贪婪葬送 —「黄金坟墓」

> 土元素达到 100

钱。钱。钱。你炒股、兼职、薅羊毛、做黄牛——你什么都干。
账户里的数字越来越长，但你的心里越来越空。
有一天，你的室友发现你被压在堆满现金和快递盒的宿舍里，已经没了呼吸。
**恶魔低语**：「你想要的都得到了，可你快乐吗？」

### 结局五：🔥 灰烬之心 —「行尸走肉」

> 火元素降至 0

你失去了所有的斗志。床以外的都是远方，手机以外都是异乡。
你翘掉了所有的课，推掉了所有的聚会。
某天，室友发现你的床铺散发出一股霉味——你已经在床上躺了不知道多久。
**恶魔低语**：「没有任何渴望的人，身体先于灵魂死去。」

### 结局六：💧 冰封之心 —「永恒的孤独」

> 水元素降至 0

你不再信任任何人。你把所有人都推开，把自己关在一个人的世界里。
慢慢地，没有人再记得你，没有人再联系你。
多年后的同学聚会上，有人问起你——没有人知道你去了哪里，也没有人在乎。
**恶魔低语**：「最深的孤独，不是没有人爱你，而是你再也不能爱任何人。」

### 结局七：🌪️ 空壳症候 —「无思之殇」

> 风元素降至 0

你的脑子越来越空。上课听不懂，考试挂科，连简单的对话都接不住。
退学通知书寄到家里那天，你拖着行李箱离开校园。
街头有人看到一个呆呆的流浪汉，目无表情地看着来往的学生——那就是你。
**恶魔低语**：「失去了思考的能力，你与蝼蚁无异。」

### 结局八：🪨 穷途末路 —「寒夜流浪」

> 土元素降至 0

你身无分文。花呗逾期、借呗逾期、校园贷催收电话一个接一个。
你不敢回宿舍，不敢见任何人。那个冬天特别冷，
第二天清晨，有人在校园角落的长椅上发现了你。
**恶魔低语**：「没有面包，谁也谈不了诗和远方。」

### 5.3 卡牌动画

- 卡牌跟随鼠标/手指拖动
- 拖动超过 30% 宽度时，显示决策影响预览（±圆圈）
- 拖动超过 60% 宽度时，自动飞出并结算
- 松手在中间区域时，卡牌回弹

## 六、技术架构

### 6.1 模块设计

```
src/
├── main.py              # 入口，启动菜单
├── core/
│   ├── engine.py        # 游戏主循环
│   ├── card_system.py   # 卡牌管理与抽卡
│   ├── player.py        # 玩家状态（四元素、时间、塔罗牌）
│   └── story.py         # 剧情树与事件触发
├── ui/
│   ├── renderer.py      # 主渲染器
│   ├── card_widget.py   # 卡牌组件（拖动、动画）
│   ├── hud.py           # 顶部HUD（时间、元素条）
│   └── ending.py        # 结局画面
├── editor/
│   ├── editor_main.py   # 编辑器入口
│   ├── card_panel.py    # 卡牌编辑面板
│   ├── tree_view.py     # 树状剧情视图
│   └── asset_import.py  # 图片/GIF/语音导入
└── data/
    └── cards.json       # 卡牌数据
```

### 6.2 数据流

```
cards.json → CardSystem 加载 → 按条件筛选可用卡牌池
→ Engine 抽取一张 → CardWidget 渲染 + 交互
→ 玩家滑动 → Player 更新四元素 → Engine 检查结局条件
→ 未触发结局 → 下一张卡牌
→ 触发结局 → Ending 画面
```

## 七、编辑器功能规划

1. **卡牌列表**：左侧树形/列表视图，支持拖拽排序
2. **卡牌编辑区**：中央面板，编辑卡面文字、左/右选项、四维影响、跳转ID
3. **剧情树视图**：可视化树状结构，展示卡牌间的跳转关系
4. **素材导入**：支持上传卡面图片（PNG/JPG/GIF）、语音（MP3/WAV）
5. **实时预览**：编辑器中预览卡牌在游戏中的外观
6. **导入/导出**：JSON格式，支持备份与分享
7. **工具栏**：顶部 Ribbon 风格，类似 Word 布局
