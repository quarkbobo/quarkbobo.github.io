# 沉浸美术与观测工具增量计划

用户允许自主选择审美和参数。本轮在既有全景舷窗内细化，不改变文章、URL和旧主题。沿用上轮设计决策，省去重复三稿。

1. 恒星采用金橙 `#ffb45b`、冰蓝 `#80caff`、珊瑚 `#ff694a`，深空 `#030710`、舱体 `#101c2b`、仪表青 `#92d9e5`。这是参照恒星冷热色彩的审美映射，不从当前光度推导温度。
2. 白热核只占中心，边缘保留颜色；以共用球几何日冕和少量镜头耀斑提高自发光感。程序星云低亮，近远星尘使用固定容量，无全屏泛白或额外后处理依赖。
3. 舷窗采用金属倒角、舱框接缝、三色弱反光。正文和底部三公式位置保持；新控件放原可收起面板，原生表单、分组展开、手机内部滚动。
4. 六项画面参数实时应用：曝光 .6—1.8、日冕0—2、星尘0—2、星云0—1、恒星展示倍率.65—1.5、尾迹辉光.5—3；只影响渲染，不改物理半径、尾迹8秒时钟或文明。
5. 物理补充软化长度0—.2、模式1边界6—40；通过复制草稿校验后原子提交。边界缩小时拒绝包含不下当前天体的输入，要求先调整初值/重置，避免暗中传送天体。
6. L1—L5按选定恒星对和瞬时轨道平面计算，明确标注圆轨道近似；四体系统不保证稳定。公式来自限制三体平衡方程，前三个数值求根，后两个等边几何。
7. 柯伊伯带意象使用64—256个无质量试验粒子；内径参数实际为内半径6—50，外半径8—60，倾角0—60°。初始绕质心运行，此后由当前四体引力积分；不反作用、不受四主体的人为边界反射。暂停/隐藏跟随主模拟时钟冻结，重置或改带参数重建。
8. 原物理16项、新模块断言、新参数原子性检查、原307浏览器检查均保持；新增真实操作和canvas差异检查，最后人工比较桌面/手机。资源缓冲有界，不新增依赖。更改运行时计算与粒子后重新执行600秒长跑。
9. 用户追加随机宇宙事件：恒星耀斑、星尘风暴、行星极光，作为纯观测特效，不改变辐照、质量或文明。种子7301，可重现；首次8—14前台运行秒、后续20—45秒间隔，由.25—3倍频率缩放；每次6—10秒，最多一个事件，强度0—2，手动触发可选类别。暂停/隐藏冻结，重置重新开始；关闭立即清除效果，固定192颗风暴粒子，不无限累积。另加“总览包含整个碎冰带”开关供完整环带观测。
