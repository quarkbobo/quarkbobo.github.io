# 三体观测主题实施计划

**Goal:** 在当前 Hexo 主题内交付可回退的空间站三体观测模式。
**Architecture:** 独立物理模块管理四体运动和文明；Three.js 场景消费同一状态；页面控制器协调主题、表单、镜头与生命周期。旧主题保持默认，新主题以按钮和 URL 参数进入。
**Tech Stack:** 已安装 Three.js 0.180.0、EJS、CSS、Node 原生测试与既有 CDP 工具。

## 约束
- 仅修改用户白名单，新增文件以 three-body 命名，文档在本目录。
- 不发布、不推送、不新增依赖，不改旧测试和配置。
- 旧场景保留行为；激活三体时隐藏并暂停旧场景。

## 数值约定
- G=1，软化0.01；模拟单位=年，1倍=1年/真实秒，基本步长1/240年。
- 模式1边界半径12，三轴反射；模式2不约束。质量范围0.000001—10，位置±100，速度±20，光度0—20，引力0.1—5，倍率0.1—10。
- 参考地表法线随自转周期20年绕Z轴旋转，初始朝+X；单星归一化辐照≥0.08且在地平线上方才计太阳。
- 辐照归一化为 Σ L/r²（UI实际公式为 I=ΣL/(4πr²)，基准 I₀=1/(4π)）。恒纪元需单日、0.5—2辐照持续5年且相邻采样变化≤10%；过热>4/退出<3.5、严寒<0.12/退出>0.16，连续5年死亡；三日连续2年死亡。
- 年份从2000起；状态滞回，死亡锁存，最近20条记录；仅新文明解锁死亡。
- 真实运行秒为尾迹时钟，寿命8秒，容量每体512点，暂停/隐藏不推进。
