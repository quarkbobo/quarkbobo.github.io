# 三体渲染优化独立审查

审查对象：最终第 3 轮的 `three-body-scene.mjs` 与 `three-body.css` 相对当前 Git HEAD 的差异。只读源码审查，不以此替代浏览器画面、性能或资源释放实测。

静态审查未发现阻塞问题。最终方案保留原有 sin hash、8 个格点的 Hermite 噪声插值、4 层 terrain 与行星三光源计算。没有保留 3D 噪声纹理或星云纹理；本轮新增的是星云球体的独立 geometry 与颜色 attribute。

- **光照与物理**：行星和大气仍逐帧从真实主体读取三恒星位置与光度，按距离平方和表面朝向计算照明。此轮未修改该逻辑、物理积分、画布分辨率和粒子容量。恒星颗粒从 8 倍频率变为 18 倍，亮面调整是美术变化，并非等价重构；小尺寸恒星的颗粒细节仍需实际近景和远景观察。
- **星云范围与连续性**：CPU 在单位球顶点计算旧星云函数，把线性 RGB 值直接存入 Float32 attribute；各通道非负，上界分别为 0.043、0.024、0.060。strength 仍实时生效，输出保留原有色调映射和颜色空间转换。没有 UV 采样或经度接缝；相同位置的顶点得到相同颜色。48×32 球面插值会平滑旧片元函数的细纹，存在局部三角形轮廓的视觉风险，需要截图确认，不能声称逐像素相同。
- **兼容与生命周期**：本地 Three 0.180 的 ShaderMaterial 使用 `vertexColors: true` 对应 `color` attribute，未引入 sampler3D、纹理格式或 GLSL 版本要求。星云 geometry 使用 clone，未污染主体共用球体；原有遍历 Set 会收集并释放它以及颜色缓冲。唯一业务纹理仍为原有 96×96 RGBA 光晕。实际上传几何数量取决于被绘制的对象，验证要求不超过 16、三轮恒定，dispose 后 geometry/texture 均为 0。
- **CSS 边界**：仅给画布及定位标签增加 `will-change: transform`。这是浏览器合成提示，不保证加速，也会增加合成层内存；未改变尺寸、坐标或交互。需在整页实测中确认标签和边框叠放正常，不能把独立 scene 测试的结果等同于整页合成性能。

曾评估的无 sin hash 已回退，不属于最终实现。候选 `yzx` 混合的对称性会令 X/Y 镜像高度相关；`zyx` 与非同倍率轴缩放可缓解这一点，但数值分布筛查不能证明画面质量或 GPU 加速。最终保留原 hash，避免把未实证的优化计入收益。

资源验证入口为 `node docs/three-body/perf-lifecycle.cjs`，专用页面复用原性能基准的四年固定物理状态。它执行三次真实创建、预热、绘制和销毁，检查 GL 像素非空、物理/环带/尾迹不变、console 无错误、唯一纹理的原生 GL 句柄已删除，以及销毁后资源归零。输出保留逐轮 PNG、构建与源码 SHA、实际资源计数。它不测帧率，也不代替整页长跑；执行结果见生成的 `perf-lifecycle-*/report.json`。
