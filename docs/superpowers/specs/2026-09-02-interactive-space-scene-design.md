# 交互式太空间场景设计

## 目标

完善博客首页首屏的太空场景，使其在不影响内容可读性、页面操作和性能的前提下具备以下效果：

- 鼠标移动时出现短暂的流星划痕尾迹。
- 桌面端完整显示星球最右侧的星环，页面不得产生横向溢出。
- 左上角品牌改为“政治月测后宫版V3/太空站”。
- 鼠标移动到星球表面时，落点附近的气体轻微浮动。
- 鼠标主键点击星球表面时，落点附近的气体产生更强烈的局部冲击并自然衰减。

## 已选方案

采用“独立流星尾迹层 + Canvas 局部纹理位移 + 保守调整星球位置”的组合方案。

未选择以下方案：

- 不把鼠标尾迹并入现有粒子 Canvas。现有粒子源文件具有哈希保护和严格生命周期契约，混入新职责会扩大回归范围。
- 不用 CSS 过滤器或整体变形模拟气体扰动。整体滤镜无法表达点击位置附近的局部气体流动，并会同时扭曲星球轮廓与固定光照。
- 不取消首页和场景的裁切保护。直接放开 `overflow` 会产生横向滚动，并可能让星环侵入正文区域。

## 视觉与交互

### 流星划痕尾迹

- 只在首页、桌面细指针设备上启用，不替换系统鼠标指针。
- 使用固定定位且 `pointer-events: none` 的独立覆盖层，位于页面内容之上但不捕获点击。
- 复用 8 个轨迹段；每次有效移动把一个轨迹段放在上一个坐标与当前坐标之间。
- 少于 4 CSS 像素的抖动不生成轨迹；单段长度上限为 72 CSS 像素，防止跨窗口跳跃形成长线。
- 轨迹视觉为青白色亮头、蓝紫色柔光尾部，线宽随速度在 1–2.5 CSS 像素之间变化。
- 每段在 260 毫秒内完成淡出和轻微收缩，不持续堆积，不产生 DOM 新节点。
- 当鼠标离开窗口、页面隐藏、背景动态暂停或系统启用减少动态时，立即清除全部轨迹。
- 粗指针和不支持悬停的设备不加载运行时监听器，不为触摸滑动生成尾迹。

### 星球气体浮动

- 交互命中采用星球 Canvas 的实际椭圆/圆面，而不是 Canvas 外接矩形；星球外部移动和点击无效。
- 悬停扰动跟随鼠标在星球表面的归一化位置，影响半径约为星球直径的 16%，仅改变气体纹理的采样位置。
- 悬停位移保持克制，以切向涟漪与轻微剪切为主；鼠标离开星球后在 240 毫秒内平滑回到基准画面。
- 主指针的左键 `pointerdown` 在点击位置产生一次局部冲击，影响半径约为星球直径的 28%，峰值位移约为悬停的 4 倍，并在 720 毫秒内衰减。
- 同一时间只保留一个点击冲击；连续点击刷新落点和能量，不建立无限冲击列表。
- 扰动不得改变星球轮廓、星环、固定光照方向或整体旋转速度。
- 暂停背景动态、粒子降级、页面隐藏、星球离屏、减少动态或粗指针策略生效时，气体交互立即停止并清空瞬态状态。

### 星环完整显示

- 保留现有前后两层星环、`-10deg` 赤道角、星环内部透明区和场景裁切边界。
- 桌面端把 `.saturn-system` 从右边界向内移动，默认使用 `right: clamp(4rem, 5vw, 5rem)`；移动端继续使用现有独立布局策略。
- 在验收视口内，旋转后星环的可见包围盒必须完全位于场景边界内，右端至少保留 8 CSS 像素余量。
- 星球和星环不得覆盖首页标题、说明、入口链接或暂停按钮，也不得产生横向滚动。

### 左上角品牌

- 页头左侧可见文字精确改为“政治月测后宫版V3/太空站”。
- 首页链接目标仍为 `/`。
- 无障碍名称同步改为“政治月测后宫版V3/太空站 首页”，避免视觉文字与朗读内容不一致。
- 采用单行显示，保留现有等宽、字距较宽的太空站视觉语言；在窄屏适度缩小字号和字距，不能挤压菜单按钮或造成横向溢出。
- 页面标题、主视觉标题和站点配置中的 `Quark's Blog` 不在本次范围内。

## 架构

### 尾迹模块

新增首页专用的 `cursor-comet.js`：

- 模板预置一个无语义覆盖层和 8 个空轨迹段。
- 模块维护固定长度的循环索引、上次指针坐标和策略状态。
- `pointermove` 处理器只保存坐标并调度一帧更新；几何计算和样式提交在 `requestAnimationFrame` 中合并。
- 所有监听器、动画帧和轨迹状态由一个可销毁生命周期拥有，重复初始化不得增加监听器或节点。
- 模块观察首页场景的 `motion-paused` 与 `particle-fallback` 类，并与 `prefers-reduced-motion`、`(pointer: coarse)`、`(hover: none)` 和页面可见性共同决定是否运行。

该模块不导入、不修改 `particle-core.js` 或 `particle-flow.js`。

### 星球核心计算

扩展 `planet-core.js`，增加纯计算的局部气体位移能力：

- `createSphereMap()` 继续在投影重建阶段预计算映射数据，并新增输出像素到投影条目的查找表。
- 基准 `renderProjectedFrame()` 保持现有确定性与快速路径。
- 新增局部扰动函数，在基准投影完成后、唯一一次 `putImageData` 之前运行。
- 扰动函数只遍历落点附近的有界矩形，通过圆形平滑衰减计算切向纹理偏移；经度采样继续首尾环绕，纬度采样继续限制在纹理高度内。
- 函数复用调用方提供的缓冲区，不在热循环创建数组、对象、Canvas 或 DOM 节点。
- 扰动只修改 RGB 采样结果并保留投影得到的 alpha 与轮廓覆盖。

### 星球生命周期

扩展 `planet-surface.js`：

- 在细指针策略下注册被动 `pointermove` 和 `pointerdown` 监听器。
- 初始、ResizeObserver 回调和滚动时，以合并帧更新缓存的 Canvas 边界；指针事件本身不得同步读取布局。
- 把客户区坐标转换为归一化星球坐标并进行圆面命中检测。
- 每帧更新悬停能量、点击能量和衰减，再把一个有界的交互状态传给核心扰动函数。
- 继续沿用现有 `canAnimate()` 阻断策略和自适应 15–30 FPS 节奏；交互不得启动第二套动画循环。
- `destroy()` 必须移除新增监听器、取消边界更新帧并清空交互状态。

## 性能与降级

- 不增加第三个 Canvas，不引入 npm 依赖或远程运行时代码。
- 指针移动期间不得逐事件创建 DOM 节点、读取布局或重建气体纹理。
- 点击和悬停只增加局部像素区域的工作；无交互能量时保持现有基准渲染路径。
- 现有桌面与移动端分辨率上限、质量降级、帧率窗口和测量指标保持不变。
- 初始化或扰动计算异常时，只隔离并降级星球 Canvas；正文、导航、粒子背景和静态星球后备仍可用。
- 现有暂停按钮同时暂停粒子、星球旋转、鼠标尾迹和气体交互。

## 测试与验收

### 自动测试

- 尾迹纯逻辑：最小距离、最大长度、速度到线宽映射、循环池复用和坐标计算。
- 尾迹生命周期：细指针启用，粗指针、无悬停和减少动态禁用；暂停、隐藏、离开与销毁清空状态；不捕获交互。
- 星球核心：悬停与点击强度差异、局部范围、确定性、经度环绕、纬度限制、alpha 保持和缓冲区复用。
- 星球生命周期：命中检测、只有主键触发、连续点击替换、衰减回归基准、阻断状态清理、缓存边界和资源清理。
- 模板与资源：尾迹只在首页加载；左上角品牌文字、链接和无障碍名称精确匹配；现有两个 Canvas 数量不变。
- 浏览器契约：气体悬停和点击产生可测画面差异；减少动态与暂停时无响应；8 个尾迹段复用且不遮挡控件。

### 视觉验收

至少验证 1440×900、1280×720、1024×768、768×1024 和 390×844：

- 星环左右两端完整，距离场景右边界至少 8 像素。
- 页面不存在横向滚动，星球与星环不遮挡文案。
- 品牌在桌面和手机上保持单行且不与菜单碰撞。
- 流星尾迹清晰但短暂，不遮蔽正文；快速移动也不会形成贯穿页面的长线。
- 悬停只产生轻微局部气体浮动，左键点击产生明显但不刺眼的局部翻涌，并在 720 毫秒左右恢复。
- 暂停和减少动态模式下画面静止，所有链接和控件仍可操作。

## 发布

- 在隔离 worktree 中按测试驱动方式实现并进行规范、质量和最终审查。
- 完整运行 `npm run test:fresh`，并对验收视口进行浏览器截图与交互检查。
- 将确认后的提交推送到 `master`，等待 GitHub Pages 工作流成功，再复核线上地址。

## 范围外事项

- 不修改文章内容、导航项目或首页主标题。
- 不替换现有粒子背景、星球纹理生成算法或静态后备设计。
- 不为触摸设备添加气体点击手势或鼠标尾迹。
- 不引入第三方光标库、WebGL、Three.js、远程图片或外部字体。
