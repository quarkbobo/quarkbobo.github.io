# 星球点击痕迹与桌面布局微调设计

## 目标

- 桌面鼠标左键点在星球有效椭圆内时，保留现有强烈气体扰动，并留下清晰但克制的蓝紫/青色云气旋涡印记。
- 印记贴合星球表面自转，约 3 秒后平滑消失；新点击替换旧印记，避免连续点击增加无界状态与绘制成本。
- 鼠标移动星尾的淡出时间由 260ms 延长到 520ms，使轨迹更容易看清，同时继续复用固定 8 个节点。
- 星球与星环作为整体仅在桌面端响应式右移 3–12px；手机端布局、裁切方式和禁用鼠标交互策略保持不变。

## 方案选择

采用单个、表面锚定的 Canvas 气体印记。相比固定在屏幕坐标的印记，它不会在星球自转时显得滑动；相比多印记池，它的状态、性能与清理逻辑更简单，符合当前单个 impact 的交互模型。

未采用独立 DOM 发光圆环，因为它难以自然贴合球面与自转，也会引入额外图层。未采用暗色陨石坑，因为它与现有气态行星的视觉语言不一致。

## 行为与数据流

1. 现有 `pointerdown` 继续只接受桌面细指针、主鼠标与左键，并用缓存边界拒绝星球椭圆之外的点击。
2. 合法点击同时启动两段状态：
   - 现有 impact 气体位移，约 720ms 衰减；
   - 新增 surface mark，保存点击时对应的球面纹理坐标，并按 3000ms 生命周期渐隐。
3. 每帧先绘制基础气体与短时 impact，再按当前自转相位把 mark 投影回可见球面；印记转到背面时不绘制，重新转回正面时仍按剩余能量显示。
4. 暂停、页面隐藏、离屏、降级、输入策略改变或销毁时，和现有 interaction 一样立即清空 mark，不保留待播放输入。
5. 新点击覆盖旧 mark，状态保持固定大小，不在动画热路径中创建 DOM、数组或计时器。

## 视觉参数

- 印记外观：中心较亮、边缘柔和的青蓝/紫色气体旋涡，不出现硬边或 HUD 圆环。
- 生命周期：3000ms；前段保持可辨识，后段平滑衰减到零。
- 影响范围小于现有 impact 扰动，使其表现为局部痕迹而不是整颗星球持续扭曲。
- 鼠标星尾动画：520ms，保留现有渐隐与缩短曲线、固定 8 节点池及 `pointer-events: none`。

## 布局

桌面 `.saturn-system` 保留现有 `right` 与尺寸约束，通过横向 transform 增加：

`clamp(3px, calc(1vw - 9px), 12px)`

该位移在中等桌面约 3–5px、宽屏约 10–12px。移动端媒体规则继续显式使用 `transform: none`，因此 390px 等手机布局保持原状。桌面几何仍要求完整星环距离场景右边至少 8px、无横向溢出且不碰撞左侧文案。

## 测试与验收

- 核心测试验证 mark 的球面锚点、可见性、强度衰减与 3000ms 结束边界。
- 渲染器测试验证合法左键启动 mark、非法按钮/触摸/椭圆外点击不启动、新点击替换旧 mark，以及所有阻塞与销毁路径清理 mark。
- 真实 Chrome 测试验证点击后 720ms 短时扰动已结束但印记仍可见，3000ms 后回到固定相位基线。
- CSS 契约与多视口几何测试验证桌面响应式右移、星环完整、文案不碰撞，以及手机端布局不变。
- 星尾测试验证动画时长为 520ms，固定节点数与禁用交互策略保持不变。
