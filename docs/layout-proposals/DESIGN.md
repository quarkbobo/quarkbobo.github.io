# 蓝色空间号 · 布局探索

本轮只制作独立原型。任务书已经确认先看两套可视化方案，原型制作直接执行；不进入生产实施、提交或部署。

## 设计前提
面向来读技术笔记、寻找游戏入口和浏览个人记录的人。首页负责同时回答“这里是谁的空间”和“我从哪里开始读”。审美延续克制电影感，星球仍是唯一强视觉。真实文本、品牌、标题、摘要、日期、分类和链接优先；不为设计添加假数据或封面。

## A · 深空档案馆（拟推荐）
大视觉引导 → 紧凑的最近更新 → 按主题找文章。把进入星球与阅读入口靠近，首屏结束露出下方内容。最近更新只展示最近两篇完整摘要，全部六篇按真实主题分组，避免六张大卡片之后重复铺六篇。

```
品牌                         首页 / 归档 / 关于
标题与两个入口                原站星球静帧
最近更新 ──────── 两篇文章摘要
按主题找文章 ──── 真实分类分组的六篇标题
```

用较大的留白保留空间感，但留白服务于主视觉；不在每张内容卡片中重复。识别点是星环的暖色与冷色文字之间的呼应。风险是内容仍需要少量滚动；如果用户优先查找，选 B 更合适。

## B · 轨道工作台
首屏左右分区：左边标题和最近两篇，右边星球；下方直接是全部主题。手机仍保持“标题 → 星球 → 最近记录”的自然阅读顺序；桌面内容与星球并置是真正的结构差异。

```
品牌                         首页 / 归档 / 关于
标题 / 最近两篇               星球 / 原站体验入口
按主题找文章 ──── 真实分类分组的六篇标题
```

更适合常回来读文章的人。代价是星球与文字争夺首屏，长标题或文字放大时更早变成单列。

## 视觉规则
共同色盘：深空 #080f1a、舱壁 #111e2d、正文 #e6edf0、次文 #a7b9c8、冷青 #8bcad8、星环暖金 #cbb389。边线 #314456。仅星球与焦点使用较强亮度，不添加全屏光晕或伪仪表数字。

A：标题使用本机宋体族（Georgia / 方正小标宋或宋体回退）体现现有站点的中文气质；正文用系统中文黑体，日期用 Consolas 等宽字体。桌面标题 68px、文章标题 46px、正文 17px；主要留白 24 / 40 / 64px。
B：同色盘偏舱壁底色，标题用黑体 48px、资料文字 15–17px、等宽日期；主要留白 16 / 24 / 40px。以布局密度区分方向，不靠换色。

手机标题自动缩至约 36px，始终可换行的长品牌；蓝色空间号保持单行，200% 文字时用更宽松响应布局保证可读。所有值尽量用 rem，控件不固定高度。

内页跟随 A：无目录文章居中约 760px 阅读栏；有目录文章保留桌面右侧粘性目录和手机正文前默认收起的原生 details。归档按真实年份分组，日期同列；游戏入口只按真实链接数组织，不给原游戏补功能。

## 预评审
放弃圆形“任务仪表盘”、虚构编号和装饰性统计，它们与现有文章无关。材料感仅由层次清楚的底色、边界和真实星球产生。NEW 继续按原有最近发布规则，不手工给旧文贴新标。星球静帧只说明构图；实际 3D 和动画体验链接到原站。

## 验证计划
先独立原型检查，再目视 1440×1000 与 390×844 截图；另测 320 / 768 / 820px 与 200% 字号。检查目标为真实可达、无页面溢出、主要入口至少 44px、焦点与目录可操作。故障注入只在临时副本加入超宽元素，证明同一溢出检查会失败。最多两轮修订，不拿静帧当运动性能证据。

## 第2轮取舍（最终）
第一轮浏览器发现390px/200%时A/B标题分别造成404/396px页面宽度；正常字号保持单行，放大时允许自然换行优先可读。生产nowrap测试保持冻结，未来若实施这项可访问性例外，需要在选定方案之后明确更新契约，不能当前改测试。

B手机改为标题→最近记录→星球→主题，使其快速找内容的优势也延续到手机；这替换了初稿两方案手机同序的设计。星球撤掉外框，静态说明保留且链接仍有44px触控高度；截图只在空白边缘柔化，没有裁掉星环。游戏符号统一占位，站内文章改用直箭头。

任务书“5个游戏”已核实为4个，且仅V4有摘要。以上结构均按真实内容调整，不凑摘要或入口。
